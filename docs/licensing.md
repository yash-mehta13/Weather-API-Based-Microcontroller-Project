# Licensing

At inspection the repository contained no LICENSE file. Without one, the code is under default copyright: others may view it on GitHub but have no granted permission to copy, modify or redistribute it. Missing licensing terms are not permission.

No license has been added here. The repository owner should choose one (for example MIT or Apache-2.0 for permissive sharing, GPL for copyleft), considering any course or institution rules, then add a `LICENSE` file. Third-party libraries keep their own licenses.
